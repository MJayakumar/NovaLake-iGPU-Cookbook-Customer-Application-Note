Application Note AN-NVL-001Rev 1.0 · 31 October 2026

Enabling the Intel Nova Lake-S Integrated GPU on Ubuntu 24.04

Device 8086:d740 (PCI 00:02.0) · xe kernel driver · Dunlow platform

This note takes a freshly installed Ubuntu 24.04 system to a fully working Nova Lake-S integrated GPU. It moves up the stack one layer at a time: packages, firmware, a patched kernel, driver detection, power management, raw engine tests, the Mesa graphics stack, and finally a real OpenGL application. Every step was run and verified on host dunlow-ecnd-2-aug2026 between 28 and 31 October 2026.

0How to use this note

Each grey box holds exactly one command. Click the copy icon at its right end, paste it into your terminal, press Enter, and compare what you see with the Expected box underneath before moving on.

  • Run everything as root. Start each terminal session with sudo -i; the prompt then ends in #.
  • Commands are written so they paste cleanly: one line each, no $ variables, no tabs, no line-continuation backslashes.
  • Run the helper scripts with bash scriptname.sh, never with source. A script that stops early would otherwise close your terminal.
  • Keep all work under /root/nvl. /tmp is wiped at every reboot.
  • Several steps use two terminals: one runs a workload, the other watches it with gputop. In MobaXterm, open a second tab to the same host.
Note. On this platform the ASPEED BMC display chip is card0 and the Intel iGPU is card1. On a board without a BMC display, the iGPU may be card0; replace card1 with card0 throughout if so. Check with ls -l /dev/dri/by-path/ after Section 4.

1Install packages

A standard Ubuntu 24.04 install has none of the build tools or graphics packages this note needs. This section installs all of them at once, including two package archives (PPAs): one for the gcc-15 compiler and one for a Mesa graphics stack new enough to know Nova Lake.

Become root.

sudo -i

If your network needs a proxy, set it first. Replace the host and port with your own; skip both lines if you have direct internet access.

export http_proxy=http://proxy-host.example.com:912
export https_proxy=http://proxy-host.example.com:912

Refresh the package lists.

apt update

Install the tool that adds package archives.

apt install -y software-properties-common

Add the archive that provides gcc-15.

add-apt-repository -y ppa:ubuntu-toolchain-r/test

Add the archive that provides current Mesa (Vulkan/OpenGL drivers).

add-apt-repository -y ppa:kisak/kisak-mesa

3Build and install the patched kernel

Two things stop the stock xe driver from using this GPU, and both must be fixed:

  1. Force-probe gate. d740 is marked as not yet officially supported. We build the kernel with DRM_XE_FORCE_PROBE="d740".
  2. Missing GuC firmware entry. The driver has no line telling it which firmware Nova Lake-S needs, so it fails with No GuC firmware defined for platform. We add that line.

A full kernel build is required. Building only the xe module against Ubuntu's headers fails to load with an Invalid relocation target error.

3.1 Confirm Secure Boot is off

mokutil --sb-state
Expected
SecureBoot disabled
Caution. The self-built kernel is unsigned. If Secure Boot is enabled, turn it off in the BIOS setup before continuing.

3.2 Get the kernel source

cd /root/nvl
wget https://cdn.kernel.org/pub/linux/kernel/v7.x/linux-7.2.6.tar.xz
tar xf linux-7.2.6.tar.xz
cd /root/nvl/linux-7.2.6

3.3 Add the Nova Lake-S GuC firmware line

This one-line Python command inserts the new entry into drivers/gpu/drm/xe/xe_uc_fw.c directly above the Panther Lake entry. It refuses to run twice.

python3 -c "p='drivers/gpu/drm/xe/xe_uc_fw.c';s=open(p).read();n='fw_def(NOVALAKE_S, GT_TYPE_ANY, major_ver(xe, guc, nvl, 70, 71, 0))';assert n not in s,'already patched';i=s.index('fw_def(PANTHERLAKE');b=s.rfind(chr(10),0,i)+1;s=s[:b]+chr(9)+n+' '+chr(92)+chr(10)+s[b:];open(p,'w').write(s);print('patched')"
Expected
patched
grep -n -A1 NOVALAKE_S drivers/gpu/drm/xe/xe_uc_fw.c
Expected
NNN:	fw_def(NOVALAKE_S, GT_TYPE_ANY, major_ver(xe, guc, nvl, 70, 71, 0)) \
NNN+1-	fw_def(PANTHERLAKE, ...  guc, ptl, ...
Caution. Position matters. The firmware table is sorted newest platform first, and the lookup loop stops as soon as it passes a platform older than the GPU. Nova Lake-S (platform number 27) is newer than Panther Lake (26), so its line must sit above the Panther Lake line. Placed below, the kernel still compiles and modinfo even lists the firmware, but the driver never finds it.

8Enable the Mesa graphics stack

Mesa provides the Vulkan (ANV) and OpenGL (iris) drivers. Ubuntu's own Mesa 25.2.8 rejects this GPU with Driver does not support the 0xd740 PCI ID. Mesa 26.1 and later include Nova Lake support behind a force-probe switch, which is set per command with the INTEL_FORCE_PROBE=d740 environment variable. Section 1 already installed Mesa 26.x.

Stop MobaXterm's X11 forwarding for this terminal, otherwise vulkaninfo aborts trying to open a window on your laptop.

unset DISPLAY
INTEL_FORCE_PROBE=d740 vulkaninfo --summary 2>&1 | grep -iE 'deviceName|deviceType|deviceID|driverName|driverInfo'
Expected
        deviceID           = 0xd740
        deviceType         = PHYSICAL_DEVICE_TYPE_INTEGRATED_GPU
        deviceName         = Intel(R) Graphics (NVL-S)
        driverName         = Intel open-source Mesa driver
        driverInfo         = Mesa 26.2.6 - kisak-mesa PPA
        ...
        deviceName         = llvmpipe (LLVM 21.1.8, 256 bits)
INTEL_FORCE_PROBE=d740 eglinfo -B 2>&1 | grep -iE 'renderer|version'
Expected
OpenGL core profile renderer: Mesa Intel(R) Graphics (NVL-S)
OpenGL core profile version: 4.6 (Core Profile) Mesa 26.2.6 - kisak-mesa PPA
OpenGL ES profile renderer: Mesa Intel(R) Graphics (NVL-S)

Optional: to apply the force-probe switch to every program for every user, add it to the system environment. It takes effect at the next login.

echo INTEL_FORCE_PROBE=d740 >> /etc/environment

11Rollback and maintenance

11.1 Boot the stock Ubuntu kernel

One-time: at power-on hold Shift (or press Esc) to open the GRUB menu, choose Advanced options for Ubuntu, then the -generic kernel. To make the stock kernel the default again:

grub-set-default `grep -o 'gnulinux-[0-9.-]*-generic-advanced-[0-9a-f-]*' /boot/grub/grub.cfg | head -1`
grub-editenv list

11.2 Return to Ubuntu's own Mesa

apt install -y ppa-purge
ppa-purge -y ppa:kisak/kisak-mesa

11.3 Long-term

  • 7.2.6-novalake is self-built and unsigned, so it receives no security updates. When a packaged kernel ships Nova Lake-S GuC support natively, move to it and remove this one. The firmware staged in Section 2 will already be in place.
  • Remove INTEL_FORCE_PROBE=d740 once Mesa enables d740 by default.
  • Source trees stay in /root/nvl for rebuilds.

05-source-load-novalake-iGPU.sh
#!/bin/bash
# 05-source-load-novalake-iGPU.sh
# Put sustained load on a chosen NovaLake-S iGPU engine (8086:d740, xe, card1)
# and measure frequency / busy time.  Uses IGT's gem_wsim workload generator.
#
# Usage (as root):  bash 05-source-load-novalake-iGPU.sh <engine> [seconds]
#   engine : render | compute | copy | video | enhance | all     (default render)
#   seconds: how long to load                                     (default 30)
# Example:  bash 05-source-load-novalake-iGPU.sh compute 60
#
# Verified 2026-10-30 (gputop): render 99.4%, compute 99.4%, copy 100%,
# video 99.4%, enhance 99.4%.  GT0 2300 MHz, GT1 1350 MHz under load.
# In 'all' mode render+compute share execution units (~80% / ~20% split).

IGT=/root/nvl/igt-gpu-tools/build
WSIM=$IGT/benchmarks/gem_wsim
ENG=${1:-render}
DUR=${2:-30}
GT0=/sys/class/drm/card1/device/tile0/gt0
GT1=/sys/class/drm/card1/device/tile0/gt1
REPS=$((DUR*100))          # each job = 10 ms, so 100 jobs per second

case $ENG in
    render)  LIST="RCS"  ;;
    compute) LIST="CCS"  ;;
    copy)    LIST="BCS"  ;;
    video)   LIST="VCS"  ;;
    enhance) LIST="VECS" ;;
    all)     LIST="RCS CCS BCS VCS VECS" ;;
    *) echo " !! engine must be: render compute copy video enhance all !!"
       return 1 2>/dev/null || exit 1 ;;
esac

echo " ********************************************************** "
echo " ***** iGPU LOAD test - Dunlow NovaLake (xe)          ***** "
echo " ***** engine: $ENG ($LIST)   duration: ${DUR}s "
echo " ********************************************************** "

if [ ! -x $WSIM ]; then
    echo " !! $WSIM not found - build igt-gpu-tools first !!"
    return 1 2>/dev/null || exit 1
fi
if [ "$(id -u)" != "0" ]; then
    echo " !! run as root (sudo -i) - GPU access and dmesg need it !!"
    return 1 2>/dev/null || exit 1
fi

echo " ********************************************************** "
echo " ** Engines this GPU exposes (xe_query query-engines)    ** "
echo " **   GT0: RENDER=rcs  COPY=bcs  COMPUTE=ccs             ** "
echo " **   GT1: VIDEO_DECODE=vcs  VIDEO_ENHANCE=vecs          ** "
echo " ********************************************************** "
$IGT/tests/xe_query --run-subtest query-engines --debug 2>&1 | grep -E '^engine'

echo " ********************************************************** "
echo " ** BEFORE load: gt0 / gt1 act_freq and cur_freq (MHz)   ** "
echo " ********************************************************** "
echo "gt0 act=$(cat $GT0/freq0/act_freq)  cur=$(cat $GT0/freq0/cur_freq)"
echo "gt1 act=$(cat $GT1/freq0/act_freq)  cur=$(cat $GT1/freq0/cur_freq)"

IDLE0_BEFORE=$(cat $GT0/gtidle/idle_residency_ms 2>/dev/null)
IDLE1_BEFORE=$(cat $GT1/gtidle/idle_residency_ms 2>/dev/null)

echo " ********************************************************************* "
echo " ** Starting load: gem_wsim, 10 ms jobs x $REPS on: $LIST "
echo " **   command per engine:  gem_wsim -w '1.<ENG>.10000.0.1' -r $REPS "
echo " ********************************************************************* "
PIDS=""
for e in $LIST; do
    $WSIM -w "1.$e.10000.0.1" -r $REPS > /tmp/wsim_$e.log 2>&1 &
    PIDS="$PIDS $!"
done

echo " ********************************************************************* "
echo " ** DURING load: sample act/cur freq every 0.2 sec                  ** "
echo " **   (one line per second; peak tracked on every sample)           ** "
echo " ********************************************************************* "
PEAK0=0; PEAK1=0; TOTAL=0
START=$SECONDS
running() { for p in $PIDS; do kill -0 $p 2>/dev/null && return 0; done; return 1; }
while running; do
    a0=$(cat $GT0/freq0/act_freq); a1=$(cat $GT1/freq0/act_freq)
    TOTAL=$((TOTAL+1))
    [ "$a0" -gt "$PEAK0" ] && PEAK0=$a0
    [ "$a1" -gt "$PEAK1" ] && PEAK1=$a1
    if [ $((TOTAL % 5)) -eq 0 ]; then
        echo "t=$((SECONDS-START))s  gt0 act=$a0 cur=$(cat $GT0/freq0/cur_freq)   gt1 act=$a1 cur=$(cat $GT1/freq0/cur_freq)"
    fi
    sleep 0.2
done
ELAPSED_MS=$(( (SECONDS-START)*1000 ))

FAIL=0
for p in $PIDS; do wait $p || FAIL=1; done

IDLE0_AFTER=$(cat $GT0/gtidle/idle_residency_ms 2>/dev/null)
IDLE1_AFTER=$(cat $GT1/gtidle/idle_residency_ms 2>/dev/null)

echo " ********************************************************** "
echo " ** RESULTS                                              ** "
echo " ********************************************************** "
if [ $FAIL -eq 0 ]; then
    echo "gem_wsim exit status        : OK (all engines finished their jobs)"
else
    echo "gem_wsim exit status        : FAILED - see logs below"
fi
echo "gt0 act_freq PEAK           : $PEAK0 MHz"
echo "gt1 act_freq PEAK           : $PEAK1 MHz"
[ -n "$IDLE0_BEFORE" ] && echo "gt0 idle during load        : $((IDLE0_AFTER-IDLE0_BEFORE)) ms of $ELAPSED_MS ms"
[ -n "$IDLE1_BEFORE" ] && echo "gt1 idle during load        : $((IDLE1_AFTER-IDLE1_BEFORE)) ms of $ELAPSED_MS ms"
echo "   (idle much lower than elapsed = that GT was busy)"

echo " ********************************************************** "
echo " ** gem_wsim output per engine (errors show up here)     ** "
echo " ********************************************************** "
for e in $LIST; do
    echo "--- $e ---"
    tail -3 /tmp/wsim_$e.log
done

echo " ********************************************************** "
echo " ** AFTER load (2 sec settle): act_freq should be 0      ** "
echo " ********************************************************** "
sleep 2
echo "gt0 act=$(cat $GT0/freq0/act_freq)  cur=$(cat $GT0/freq0/cur_freq)"
echo "gt1 act=$(cat $GT1/freq0/act_freq)  cur=$(cat $GT1/freq0/cur_freq)"

echo " ********************************************************** "
echo " ** dmesg: GPU hang / reset check (empty = good)         ** "
echo " ********************************************************** "
dmesg | grep -iE 'hang|reset|wedged' | grep -iE 'xe|0000:00:02.0' | tail -5

echo ""
echo " ##################################################################### "
echo " ##  TIP: in a SECOND terminal, run gputop while this script runs  ## "
echo " ##  to see per-engine busy %  (rcs vcs vecs bcs ccs columns):     ## "
echo " ##     $IGT/tools/gputop                                            "
echo " ##  (intel_gpu_top does NOT support xe - it says use gputop)       ## "
echo " ##################################################################### "

gl_load_novalake.py
#!/usr/bin/env python3
# gl_load_novalake.py - headless OpenGL load on the NovaLake-S iGPU via Mesa (iris)
# Renders a heavy fragment shader into an off-screen 4K framebuffer for N seconds.
# Usage:  python3 gl_load_novalake.py [seconds]      (default 30)
import os, sys, time

os.environ.setdefault("INTEL_FORCE_PROBE", "d740")   # Mesa force-probe for d740
os.environ.setdefault("EGL_PLATFORM", "surfaceless") # no monitor / X needed
os.environ.pop("DISPLAY", None)                      # ignore MobaXterm X11 forwarding

import moderngl

DUR = float(sys.argv[1]) if len(sys.argv) > 1 else 30.0
W, H = 3840, 2160

print(" ********************************************************** ")
print(" ** Creating headless OpenGL context (EGL surfaceless)   ** ")
print(" ********************************************************** ")
ctx = moderngl.create_context(standalone=True, backend="egl",
                              libgl="libGL.so.1", libegl="libEGL.so.1")
print("GL_RENDERER :", ctx.info["GL_RENDERER"])
print("GL_VERSION  :", ctx.info["GL_VERSION"])
if "llvmpipe" in ctx.info["GL_RENDERER"].lower():
    print(" !! Running on llvmpipe (CPU), NOT the iGPU - check INTEL_FORCE_PROBE / Mesa !!")

prog = ctx.program(
    vertex_shader="""
        #version 330
        in vec2 in_pos;
        void main() { gl_Position = vec4(in_pos, 0.0, 1.0); }
    """,
    fragment_shader="""
        #version 330
        uniform float t;
        out vec4 color;
        void main() {
            vec2 p = gl_FragCoord.xy * 0.001;
            float v = 0.0;
            for (int i = 0; i < 200; i++) {          // heavy per-pixel math
                v += sin(p.x * float(i) + t) * cos(p.y * float(i) - t);
                p = p.yx * 1.0001 + 0.01;
            }
            color = vec4(fract(v), fract(v * 0.5), fract(v * 0.25), 1.0);
        }
    """,
)
vbo = ctx.buffer(bytes(__import__("array").array("f", [-1, -1, 3, -1, -1, 3])))
vao = ctx.simple_vertex_array(prog, vbo, "in_pos")
fbo = ctx.simple_framebuffer((W, H))
fbo.use()

print(" ********************************************************** ")
print(f" ** Rendering {W}x{H} frames for {DUR:.0f} s - watch gputop (rcs) ** ")
print(" ********************************************************** ")
frames, start, last = 0, time.time(), time.time()
while time.time() - start < DUR:
    prog["t"].value = time.time() - start
    vao.render()
    ctx.finish()                       # wait for the GPU so timing is real
    frames += 1
    now = time.time()
    if now - last >= 1.0:
        print(f"t={now - start:5.1f}s  frames={frames:6d}  avg FPS={frames / (now - start):7.2f}")
        last = now

el = time.time() - start
print(" ********************************************************** ")
print(f" ** RESULT: {frames} frames in {el:.1f} s = {frames / el:.2f} FPS at {W}x{H} ")
print(" ********************************************************** ")
